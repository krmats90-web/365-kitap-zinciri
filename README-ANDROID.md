# 365 Gün Kitap Zinciri

Bu klasör bir PWA'dır. Android Chrome üzerinden HTTPS ile yayınlandığında uygulama gibi ana ekrana kurulabilir.

## Kurulum
1. Bu klasörü HTTPS destekleyen bir web hosting hizmetine yükleyin.
2. Telefonda Chrome ile oluşan siteyi açın.
3. Sayfadaki “Ana ekrana uygulama olarak ekle” düğmesine dokunun veya Chrome menüsünden “Ana ekrana ekle / Uygulamayı yükle” seçeneğini kullanın.
4. Uygulama açıldığında işaretler cihazın tarayıcı hafızasında saklanır ve çevrimdışı çalışabilir.

Başlangıç: 3 Ekim 2026
Bitiş: 2 Ekim 2027
Günlük hedef: 25 sayfa
